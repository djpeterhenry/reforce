## Summary (hand-written; preserved when the script regenerates this file)

733 scene files scanned (206 WaveShape, 119 Particle, 352 FlowField, 15 FlowField Union, 37 ColorMap, 4 Sprite).
With the lexer rules below, every file tokenizes and all but 2 expressions parse under the documented
operator grammar plus `{...}` array literals.

Surprises / things a parser must handle:

- **Array literals `{a, b, ...}`** (246 uses, WaveShape/Particle/FlowField), nestable and negatable (`-{...}`),
  passed to `map1D`, `choice`, `col`, `row`, `select`, `transpose`, etc. Some contain 400–500 elements;
  one expression is 21 KB long.
- **Undocumented functions**: `col`, `cols`, `row`, `rows`, `select`, `choice`, `vector`, `vectorLR`,
  `map1D`/`map2D`, `transpose`, `subrange`, `resample`, `dot`, `largest`, `smooth`, `noise`, `pow`, `ceil`.
  Several take variable argument counts (`choice` 1–6, `select` 3–6).
- **Any key is a variable**: expressions read `NUM` (as do 200+ others), and also ad-hoc keys like `Star`,
  `Side`, `Coil`, `Divs`, `X`/`Y`/`Z`, `AVRG`. Identifiers (keys, vars, built-ins *and* functions) are
  case-insensitive in practice: `a0`/`A0`, `pi`/`Pi`/`PI`, `map1d`/`map1D`, `ABS`, `wraP`.
- **Self/forward references** within a family (`B0="... B0 ..."`, `C0` using `C0`): 280+ occurrences, i.e. B
  vars carry state from the previous frame and C vars from the previous `s` step. Evaluation order and
  initial values (0?) matter.
- **Multiple entries on one line separated by `,`** (`AVRG=11, DCAY=.7`) and C-initializer style trailing
  commas after values (`A0="...",`) in 36 files.
- **Quoted strings span lines** (94 values, up to 63 lines). Newlines inside quotes are whitespace.
- **Empty values** `A2=""` (303) must be accepted (treat as 0 / undefined).
- **Duplicate keys** in 12 files (last-wins vs first-wins must be decided; G-Force behavior unknown).
- **`Meta="reactive=4 detail=4 ..."`** is a metadata string, not an expression.
- **Typos that G-Force tolerates**: `NUM_FTT_BINS`, `rnd16`, `1L` numeric suffix, `.5.5` / `.1.5` double-dot
  literals, bare stray text outside comments (3 files, e.g. an author byline and a lone `w`). No reference to an
  undefined A–D var remains once comma-separated entries are parsed (a naive line-based parser would
  report two). Unknown identifiers presumably evaluate to 0.
- **Line endings**: LF, CRLF, mixed CRLF+LF, and one file mixing CR and CRLF; 264 files lack a final newline.
  4 UTF-8 and 2 8-bit (Latin-1/MacRoman) files — non-ASCII only ever appears in comments.
- **`#` tags in comments**: `#waveshape-particle-only` (117 Particle files) and `#waveshape-particle-also`
  (27 WaveShape files) control which pool a WaveShape config joins.
- Operators actually used: `+ - * / % ^ ( ) , { } == != < > <= >= && || ! ^^` (unary `-` and `!`).
  Not seen: `?:`, `&`, `|`, `<<`, `>>`, casts, hex or `[]`.
- Number literals: integers, `0.5`, `.5`, `5.` (once), exponent `1e30`; unquoted `-1` values.
