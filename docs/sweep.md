## Notes on the former failures (2026-11-11, offline, from the 18:15–18:35 captures)

Before → after: **FlowFields 337/352 → 348/352 → 349/352, ColorMaps 233/250 → 250/250** (probe parity: no unexpected failures; 166/186 incl. runs 15–23, docs/parity.md).
New semantics are in docs/scene-format.md and docs/probe-results.md #25–#29 and #36. All 349 comparable FlowFields
now pass; only the 3 rnd-load configs remain.

Causes found:
1. **`%` is an integer remainder** (operands truncated toward zero), not `fmod` (#25).
2. **FlowField pixel grid: edge pixels on the frame edges**: x = −1 + 2c/(W−1), y = 1 − 2r/(H−1), same rule when
   mapping sources back (#26). reforce used pixel centers; G-Force's grid shows in per-row integer/wrap tests and near
   1/sin singularities.
3. **WaveShape lines pass through the center of pixel (x+1)·W/2** (+0.5 px) (#27).
4. **Fixed-point source rounding**: float32 error put exact-row sources 1 ulp low, which picked up 15/16 of the
   neighboring row ("Bits Between Bits" rows decayed into their neighbors). Sources are snapped to 1/16 px with a small bias.
5. **PNG strips are read like a linearly filtered texture** (x = k/255·N − 0.5, clamped) (#28).
6. **A ColorMap's `t` is config-local** (0 when it starts; also in its load tiers) (#29). The time maps were never
   inherently incomparable: the sweep shoots 0.7 s after each cut, so both sides are at t = 0.7.
7. **`Aspc=1` FlowField grid has square pixel steps**: the long axis spans ±(long−1)/(short−1) (1979/1259 at
   1980×1260), not ±long/short (#36). Found with Nebula; it also tightened 110 other fields (mean mad of the exact
   classes 0.480 → 0.372, none worse by > 0.05; e.g. Unholy Ritual (Temple Mix) 2.39 → 0.33, Shattered 1.46 → 0.32,
   Fran 10a 1.23 → 0.19, Snowflake Squares (Circle Mix) 1.42 → 0.41).
